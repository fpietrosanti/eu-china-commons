【新项目 · 研究启动】中欧数字公地观察站 🇪🇺🤝🇨🇳

各位朋友好！我正在发起一个开放的研究项目：**中欧数字公地观察站**（Europe–China Digital Commons Observatory）。

开源软件、开放标准、开放数据，正在成为数字经济的公共基础设施。欧洲与中国都在通过公共资金、产业政策和开源基金会大力投入——但双方对彼此的了解仍然很少。

我们希望：
🔹 梳理中欧（以及欧盟各成员国、中国各省市）由公共资金支持的开源项目；
🔹 研究开源相关的产业政策及其经济影响；
🔹 建立中欧数字领域研究机构、基金会、企业与合作机制的目录；
🔹 以事实和证据为基础，促进中欧在数字公地上的对话与合作。

目前项目处于**初期研究阶段**，所有数据和方法都公开在 GitHub 上。

📣 **诚邀加入！** 如果您是研究人员、开源社区成员、基金会或企业从业者、政策专家，或对中欧数字合作感兴趣，欢迎联系我们，一起参与资料收集、审校和研究合作。
