# 宣言与使命 — 中欧数字公地观察站

*中文译文将由母语人士审校，以[英文版](https://eu-china-commons.eu/manifesto/)为准。*

## 宣言 — 共建数字公地

欧洲和中国运行在同一套开放基石之上：操作系统内核、密码库、编译器、开放指令集与开放标准。双方都已将开源视为战略方向，也都在投入，只是方式不同。任何一方都无法独自守护双方共同依赖的代码。

**我们相信：**
1. **数字公地是基础设施，不是战场。** 采用开放许可的代码是公共产品，每多一位使用者和贡献者，其价值就增长一分，无论其国籍。
2. **上层竞争，底层共建。** 产品与市场可以竞争；其下共享的基础层，最好共同维护。
3. **自主可控，在于能读懂、能维护、能修改、能分叉，而非自我封闭。** 开源是唯一无需围墙的数字自主，并在合作中不断增强。
4. **一次投入，处处复用。** 一个公共部门出资开发的软件，应能为国内外其他公共部门所用。
5. **科学在开放中生长。** 共享的科研软件、数据和模型，是天然的桥梁。
6. **以证据建立信任。** 资金与治理透明，开展安全审查，遵守双方法律。
7. **中立平台，小步前行。** 依托开放治理的基金会和标准组织，迈出可衡量、可推广的具体步伐。

**如果你认为这件事应该发生，并认同这些前提，你已经是我们中的一员。**

## 使命

**以开放研究和广泛参与，推动中欧数字公地合作。**

观察站通过两条相互促进的路径，将本宣言付诸实践：

1. **开放研究。** 我们梳理欧洲和中国在各个层面——从欧盟和中央政府到城市、基金会与社区——如何制定开源与数字公地政策、提供资金、开展治理和推动复用。所有来源均存档，每项论断均标注性质，所有数据开放、可纠正。研究保持独立：服务于合作，不为任何政府或企业代言。
2. **利益相关方参与。** 我们把研究证据带给塑造这些政策的各方——公共部门、科研资助机构、基金会与社区、企业、高校以及外交机构——让他们看到在数字公地上开展合作的潜力和具体机会，并**参与研究本身**：提供案例和数据、纠正我们的结论、共同提出研究问题。

**目标：** 一份由利益相关方共同建设、共同拥有、基于证据的中欧数字公地非竞争性合作议程。
