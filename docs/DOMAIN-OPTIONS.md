# Brand and .eu domain — 30 options (for decision)

DNS check of 3 Nov 2026: every name below except silkcode.eu returns NXDOMAIN, so it is *probably* free. **Confirm at an EURid registrar** before deciding. The registrant must be resident in the EU/EEA.

## Fabio's proposal: `europe-china-digital-commons.eu`
- **For:** it mirrors the naming of `digital-commons-edic.eu`, so European institutions place it immediately; it is descriptive and good for SEO (the "digital commons" keyword); it is neutral.
- **Against:** it is long (31 characters + .eu) and the EU comes first, while Chinese usage is 中欧 (China–Europe). The similarity to the DC-EDIC's domain could also suggest an official link, so the site must say clearly that it is independent (it already does, in the footer and the charter).
- **Mitigation:** register the reverse order **`china-europe-digital-commons.eu`** too and point it at the ZH version, plus a short alias for social media and print.

## Recommendation (4 domains, about €40/year)
1. **`europe-china-digital-commons.eu`**: main domain, EN.
2. **`china-europe-digital-commons.eu`**: redirects to /zh/.
3. **`zhongou-commons.eu`**: short alias for WeChat/Weibo and printed material in China.
4. **`eu-china-commons.eu`**: short alias for European social media and slides.

- **Name:** EN *Europe–China Digital Commons Observatory*, ZH **中欧数字公地观察站**.
- **Social handle:** the same short name everywhere, e.g. `@EUChinaCommons` / 中欧数字公地.
- **Before registering:** quick EUIPO/CNIPA trademark search, and a check of the names on WeChat and Weibo.
