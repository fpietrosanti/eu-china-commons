欧洲

openDesk——德国主权办公平台

面向公共行政领域的开源办公与协作套件，由德国联邦数字主权中心 ZenDiS 负责维护。它整合现有开源组件，而非另起炉灶，便于其他行政机构复用同一参考技术栈。

欧洲

La Suite numérique 与 Docs——法、德、荷协同

法国跨部委数字局（DINUM）为公务员开发开源协作工具。其协同编辑器 Docs 基于开源组件 BlockNote 构建，该组件被 DC-EDIC 列为优先共享公地。

欧洲

政府中的 Matrix——法国 Tchap 与德国 BwMessenger

多个欧洲行政机构基于开放、联邦式的 Matrix 协议运行各自的即时通讯系统。各自独立部署服务器，又可互联互通——DC-EDIC 通讯赛道正采用这一模式。

欧洲

Developers Italia 与 publiccode.yml——依法复用

意大利《数字行政法典》第69条规定，公共机构须公开其委托开发的软件，供其他机构复用。国家软件目录及源自意大利的 publiccode.yml 元数据标准，现已在欧洲层面被引用。

欧洲

X-Road——爱沙尼亚的数据交换层，跨境共享

支撑爱沙尼亚电子政务的开源数据交换层，由共同设立的机构（NIIS）与芬兰等国联合开发，并被全球多国复用。

欧洲

主权技术局（Sovereign Tech Agency）与欧盟主权技术基金试点

德国主权技术局资助全球依赖的开源基础设施的维护工作，现于 DC-EDIC 框架内运营欧盟主权技术基金试点：经公开征集遴选，与可信维护者签订范围明确的工作合同。

中国

openEuler——面向公共与关键基础设施的社区操作系统

捐赠给开放原子开源基金会、由多家企业共建社区开发的 Linux 发行版，据报道已在中国电信、金融及公共部门服务器中广泛部署。规模数据仍需独立核实。

中国

开源鸿蒙在公共基础设施中的应用

深圳、重庆等地的市级政策支持开源鸿蒙在交通、工业控制和仪器仪表等领域的应用，以公共激励推动跨行业复用同一开源底座。实际部署情况正在核实中。

中国

木兰许可证——获国际认可的公共许可证基础设施

中国制定了中英双语开源许可证。木兰宽松许可证第2版于2020年获开放源代码促进会（OSI）批准，表明中国的法律工具能够融入国际开源治理。

中国

地方开源资金——杭州、广东、深圳、江苏

中国多个省市资助项目孵化（杭州，最高100万元）、社区运营成本补贴（广东，补贴30%，上限800万元）及应用推广（深圳，最高15%）。江苏宣布规划不低于10亿元的基金矩阵。以上均为公布的资金规模，而非已核实的实际支出。

中欧桥梁

Eclipse Oniro ↔ 开源鸿蒙——“姊妹项目”

自2021年起，Eclipse 基金会（布鲁塞尔）与开放原子开源基金会（北京）共同推进两个治理独立、技术协同的项目，并于2024年共同确定 Eclipse 公共许可证2.0中文译本，并于2026年3月延续交流机制。

中欧桥梁

RISC-V 国际基金会——以瑞士为法律所在地的开放标准

该开放指令集标准的运营机构于2020年将法律注册地迁至瑞士。欧洲与中国成员共同参与同一规范的制定，香山等中国开源处理器即基于该规范实现。

中欧桥梁

源自中国、在欧洲使用的 Apache 项目

多个由中国企业和高校发起的数据基础设施项目（如 Apache DolphinScheduler、ShardingSphere、Doris、IoTDB）已在 Apache 软件基金会的中立治理下成功毕业，并拥有欧洲用户——这体现了一种无需政府直接参与的跨国协作模式。

中欧桥梁

社区桥梁——开源社与开放源代码促进会

开源社成立于2014年，是由志愿者运营、厂商中立的中国开源社区，自2016年起为 OSI 附属成员，每年发布《中国开源年度报告》——与 DC-EDIC 的《数字公地现状》报告天然对应。

中国

开源鸿蒙应用创新实验室——深圳市龙岗区

深圳市龙岗区设立公共实验室，帮助本地企业和公共服务基于开源鸿蒙进行开发，由地方政府担当共享开源底座的召集者。

中国

Gitee——工业和信息化部支持的代码托管平台

工业和信息化部选定 Gitee 建设独立的国家级代码托管平台，部分原因是为了防范无法访问境外平台的风险。欧洲也在以同样的思路讨论自主代码托管平台。

中欧桥梁

“中欧开源”主题演讲，2025年欧洲开源峰会

2025年8月在阿姆斯特丹举行的欧洲开源峰会上，OSS-Compass（华为）与西班牙 Bitergia 公司联合发布中欧开源贡献数据，并提出互补合作路径。产业界已在讨论，政策层面尚未跟进。
