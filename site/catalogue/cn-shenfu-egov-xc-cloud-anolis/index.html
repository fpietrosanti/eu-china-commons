Shenfu Reform and Innovation Demonstration Zone (Liaoning) e-government XC cloud runs Anolis OS 8.9

ChinaPublic-sector reuse evidence B verified

Case study published by the OpenAnolis community (Aliyun developer community, 22 Nov 2024): phase I of the Shenfu demonstration zone XC government cloud uses 50 Loongson servers, all running Anolis OS 8.9 (community edition, open source), with a Loongson national-crypto cloud platform on top; it hosts party-and-government XC and other applications. Fact (as reported by vendor/community): a named government-zone e-government cloud deployed on an open-source OS. Won the OpenAnolis 2024 mid-year best user case award.
