Shijiazhuang market-supervision platform phase II specifies openEuler 22.03 LTS

ChinaPublic-sector reuse evidence A verified

Requirements document of the Shijiazhuang municipal Smart Market Supervision Platform phase II (Shijiazhuang Data/Big Data Bureau site, 3 Jun 2024) specifies the server environment "操作系统：openEuler-22.03-LTS". Fact: a named municipal government system is specified to run on openEuler.

since
2024-06
scale
municipal government application
note
Round 6 (2 Nov). Lead from Qwen, verified by Claude (pdftotext, 49 pp). Requirement spec, not proof of go-live; first named government application (not just a cloud OS option) found on openEuler.
