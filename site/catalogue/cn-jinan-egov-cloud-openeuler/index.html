Jinan e-government cloud price list includes open-source OS (Ubuntu / openEuler / Anolis)

ChinaPublic-sector reuse evidence A verified

Jinan Big Data Bureau 2024 departmental final accounts (PDF on jndsj.jinan.gov.cn, Jan 2026 upload): the e-government cloud service price list has a line "开源操作系统 Ubuntu/open 欧拉/龙蜥等, 套*月, 64位" at 28.26 yuan per set-month, next to Windows Server at 60.56. Fact: the municipal government cloud bills open-source OS (incl. openEuler) as a standard service, at under half the Windows price.
