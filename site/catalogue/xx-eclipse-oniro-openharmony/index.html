Eclipse Foundation (Brussels) and OpenAtom: Oniro for OpenHarmony

EU–ChinaExisting collaboration evidence ? partly verified

The Eclipse Foundation hosts the Oniro for OpenHarmony project to extend the OpenHarmony code base for European and global markets, in collaboration with OpenAtom. The US House Select Committee questioned this in a letter of 4 June 2025. The letter cites the Eclipse project page; the project page itself was not fetched.
