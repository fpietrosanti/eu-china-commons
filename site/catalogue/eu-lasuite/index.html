La Suite numerique (DINUM, France): Docs, Visio, Tchap

EuropePublic-sector reuse evidence A-v verified

State collaborative suite for French public agents, hosted in France (SecNumCloud at Outscale except Tchap), code on GitHub under MIT/AGPL, single sign-on via ProConnect. Docs uses the Dutch BlockNote editor and is reported as co-developed with Germany (ZenDiS). A DINUM presentation of March 2026 cites 400K monthly active users on Tchap and 100K on Visio; the Cour des comptes criticised low adoption in 2024.
