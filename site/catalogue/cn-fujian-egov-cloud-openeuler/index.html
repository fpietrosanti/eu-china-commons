Fujian provincial e-government cloud offers openEuler 20.03 as default server OS

ChinaPublic-sector reuse evidence A verified

The official IaaS service-registration form of the Fujian Provincial E-Government Cloud Computing Platform (published on xxzx.fujian.gov.cn, PDF dated 9 May 2025) lists openEuler-20.03 (64-bit) as the DEFAULT operating system offered by the platform operator (星云公司), alongside NeoKylin V7.0 and Kylin Advanced Server V10. Fact: openEuler is the default OS of a provincial government cloud open to all provincial bodies. Not shown: number of VMs actually running it.
